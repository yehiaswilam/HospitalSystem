# Hospital Appointment System (ASP.NET Core MVC)

## How to run
1. Install the .NET 8 SDK
2. Open a terminal inside this folder
3. Run:  `dotnet run`
4. Open the URL shown in the terminal (e.g. http://localhost:5000)

The SQLite database (`hospital.db`) is created automatically with 6 seeded doctors.
To use Visual Studio: open HospitalSystem.csproj and press F5.
